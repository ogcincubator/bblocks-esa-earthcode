# ESA EarthCODE Building Blocks

EarthCODE metadata profiles (GeoDCAT / STAC / OGC API Records) for experiments, products and workflows,
with their workflow provenance linked to the Open Science provenance profiles.


Building blocks describing the metadata published by [ESA EarthCODE](https://earthcode.esa.int/) in the
[Open Science Catalog](https://opensciencedata.esa.int/). They build on the
[Open Science Workflows Building Blocks](https://ogcincubator.github.io/bblocks-openscience/) register.


## Building Blocks
